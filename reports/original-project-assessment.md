# Original university project assessment

## Implemented source code

The supplied training script performs the following operations:

1. Reads the Excel workbook from the current directory.
2. Removes rows where `price <= 0`.
3. Creates `high_rating` from `rating >= 4.6`.
4. Uses year, price, review count, page count, genre, and sub-genre as features.
5. Standardizes four numeric features and one-hot encodes two categorical features.
6. Fits a 300-tree Random Forest on every cleaned row.
7. Attempts to serialize the pipeline with Joblib.

The script contains no held-out evaluation, cross-validation, dummy baseline, metric calculation, tuning, confusion matrix, or SHAP analysis. Training on the complete dataset is acceptable for a final deployment refit only after an evaluation protocol has selected the model. In the original script, no such protocol is reproducible.

The original `FunctionTransformer` uses an anonymous lambda to densify preprocessing output. Anonymous functions are fragile across processes and are unnecessary because the selected sklearn estimators accept the pipeline output directly.

## Application behavior

The original Streamlit application loads `book_high_rating_model.pkl` during startup without handling a missing, incomplete, or incompatible artifact. It accepts free-text genre fields even though training uses a fixed categorical vocabulary. It labels the output as recommendation support despite having no user-specific inputs or ranking implementation.

The portfolio interface replaces free text with controlled categories, validates all numeric ranges, handles artifact errors, labels the probability precisely, and explains the academic scope.

## Saved artifact

The supplied 3,054-byte Joblib file was not loaded because serialized Python objects can execute code. Static inspection found sklearn preprocessing and column-transformer state but no `RandomForestClassifier`, `estimators_`, fitted class state, or anonymous transformer. The binary therefore cannot satisfy the application's expected classifier contract and is not included in the portfolio repository.

The rebuilt artifact is generated by the documented command, contains a complete fitted pipeline, and was loaded in a separate Python process before inference testing.

## Report-only claims

The final report describes Naive Bayes, Logistic Regression, SVM, Random Forest, Gradient Boosting, XGBoost, GridSearchCV, and SHAP. None of those experiments beyond the Random Forest deployment script can be reproduced from the supplied source code. Several Stage 3 documents also disagree about the target, naming either `high_rating` or genre/sub-genre classification.

Historical tables are preserved separately and are not merged into the reproduced benchmark.
